# Glass Keys – Virtual Keyboard ⌨️

### A Little Glass, A Lot of Focus.

Glass Keys is a modern virtual keyboard featuring a beautiful Glassmorphism design. Users can type using on-screen keys or their physical keyboard.

### ✨ Features
- Modern Glassmorphism UI
- Interactive virtual keyboard
- Physical keyboard support
- Character counter
- Backspace and Enter keys
- Caps Lock functionality
- Clear All button
- Responsive design

### 🛠️ Technologies
- HTML5
- CSS3
- JavaScript
